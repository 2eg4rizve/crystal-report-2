## Fixes found by real testing

- Named GET routes were added so POST responses can generate their `201 Created` Location header; previously `CreatedAtRoute` failed after saving.
- `MinLengthAttribute` was removed from `List<T>` because the .NET Framework implementation attempted an invalid array cast. Empty-item validation remains authoritative in `InvoiceService`.
- Error details are disabled globally so unexpected production failures do not expose stack traces.
